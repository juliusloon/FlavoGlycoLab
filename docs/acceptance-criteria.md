# 分阶段最低验收标准

## G0/G1：独立性和治理
- 新Git内无未批准来源/模型数据；本地证据加载无需其它仓库；来源文件SHA核验。
- 所有活动模块名/包名和绝对路径与正式项目名一致。
- PROJECT/ARCHITECTURE/STATE/PROGRESS、TASK/REPORT/ADR模板及索引齐全且职责不重叠。
- TASK/REPORT同号同短名；每项实质操作有真正的执行核验。

## S1：真实案例
- 身份/连接位点/来源记录及反应方向对应原始文献或可核证来源。
- 21个结构命中清楚标记可能的同源与非酶法情形。
- 每项教学准入有具名专业人员审查、日期、判断及禁止用途。
- 不允许仅凭机器审核或名称匹配提升为teacher_approved。

## S2：实验数据驱动仿真
- 所有输出数值有真实观测、上下文条件、单位和方法，能追溯/重放；不随意构造动力学。
- 真实D1范围外有受控拒绝或概念性指导，不输出伪结果。

## E1/E2：课程和应用
- 按批准合同验收24步内容、分角色权限、过程记录、循证AI及安全边界；scaffold不算实现。
- 自测通过不代替独立教师验收。

## R1：发布
- 对每类源/模型/图示/实验数据的再分发许可逐项通过。
- 私有数据不进入Git、浏览器、发布镜像或API泄漏路径；通过安全、内容与平台的独立审核。
