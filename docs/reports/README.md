# REPORT 事后事实索引

每个执行中的TASK都应有匹配REPORT。REPORT记实际diff、验证、偏差、阻断和局限，不能授权新的范围。失败/阻断/部分完成也须诚实报告。

- REPORT-001-standalone-data-foundation.md：为既有TASK-001补齐当时已完成的事实归档（工程验证，不追认教师审核）。
- REPORT-002-governance-and-rename.md：本次更名和CondRxnBench式治理落地及实际复核。

- REPORT-003-progress-public-repository.md：进展目标对照、公开范围审计、独立公开快照和GitHub同步验收。

命名规则REPORT-NNN-short-title.md，编号和短名严格匹配TASK；使用TEMPLATE.md。REPORT保存历史，STATE保存最新事实。没有对应验证数据不写“通过”。
