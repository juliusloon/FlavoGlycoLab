## 一、这个项目是什么（约 2 分钟）

项目叫 FlavoGlycoLab，目标是建设一个**可教学、可审计、可交互**的黄酮糖苷酶法合成与生物制造虚拟实验平台，首个案例是异槲皮苷的酶法制备。

有三条边界从第一天就定死了，今天原样汇报：

1. **三个状态门互不自动晋级**：研究证据通过 ≠ 教师审定通过 ≠ 可以公开发布。任何一层都不能拿下一层的结论充数。
2. **所有教学数值必须有审定来源**；来源缺失就明确标缺失，系统不允许编造。
3. **原始文献和第三方材料只读、SHA 固定**；三篇核心论文的 PDF 经所有者明确指令在仓库内公开，但出版方权利核验状态仍是"未核验"，这不追认为授权。

以三篇文献为证据核心：Pei 2019、Zhang 2015、Niu 2024，分别对应三条酶法制备路线。
