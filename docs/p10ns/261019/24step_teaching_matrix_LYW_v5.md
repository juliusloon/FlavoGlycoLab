## 实验总目标与路线

探究用不同底物、不同催化剂制备异槲皮苷有什么不同，重点比较反应方式、所需条件、反应时间、目标物生成情况及可能杂质。

| 路线 | 底物与催化剂 | 主要反应 |
| --- | --- | --- |
| R1 双酶糖基化 | 槲皮素；UGT与蔗糖合酶 | 给槲皮素加糖，配合糖供体再生 |
| R2 选择性水解 | 芦丁；α-L-鼠李糖苷酶 | 去掉芦丁上的鼠李糖，保留葡萄糖 |
| R3 工程菌转化 | 外加槲皮素；工程化枯草芽孢杆菌 | 细胞利用胞内糖供体，把槲皮素转为目标物 |

三条路线共用24步；可分组完成一条再交流，也可保存一条后用“开始新实验”依次完成其他路线。

## 六界面与24步

### 界面一 案例与路线（01—04）

| 步骤 | 教学任务 | 学生操作与思考 |
| --- | --- | --- |
| 01 | 明确实验任务 | 围绕“不同底物、不同催化剂制备异槲皮苷，有什么不同”提出自己的初步想法。 |
| 02 | 认识底物和产物 | 比较槲皮素、芦丁和异槲皮苷，找出它们在糖基上的差别。 |
| 03 | 比较三条路线 | 查看三张路线卡，辨认各路线用什么底物、什么催化剂，属于加糖还是去糖。 |
| 04 | 选择路线并说明理由 | 选择一条路线，在“我的选择依据”写出理由，确认进入实验台。 |

### 界面二 配置反应体系（05—08）

| 步骤 | 教学任务 | 学生操作与思考 |
| --- | --- | --- |
| 05 | 选择底物 | R1、R3选槲皮素；R2选芦丁。说明该底物怎样变成异槲皮苷，再加入体系。 |
| 06 | 选择催化剂 | 按路线选择“UGT与蔗糖合酶”“α-L-鼠李糖苷酶”或“工程化枯草芽孢杆菌”，说明其作用并加入。 |
| 07 | 选择供体方案 | R1选“供体与再生方案”；R2选“不引入糖基化供体”；R3选“细胞内供体供给方案”，解释选择并加入。 |
| 08 | 确认体系是否合理 | 核对底物、催化剂与供体是否配套，说清加糖或去糖的过程，再进入条件设置；有疑问时向右侧AI导师提问。 |

## 最后集中比较什么

将三组记录按下表汇总，每项分别写出R1、R2、R3的情况；有数据写数据，只有定性证据就写观察，没有依据则写“待补”。

| 比较项目 | 学生需要回答的问题 |
| --- | --- |
| 底物与反应方式 | 从槲皮素还是芦丁出发？需要加糖还是去糖？ |
| 催化剂与供体 | 用纯酶体系还是细胞体系？是否需要外加糖供体或供体再生？ |
| 反应条件与操作 | 温度、pH等条件有什么不同？配制、培养或取样操作有什么特点？ |
| 时间与制备效果 | 各自反应多久？得到多少异槲皮苷？比较时是否注明时间、投料和指标？ |
| 产物组成与后处理 | 除目标物外，还有哪些残余底物或其他成分？后续需要怎样处理？ |
| 路线选择 | 在给定原料、时间和实验条件下，选哪条路线？依据是什么？ |

## 希望学生形成的认识

- 目标相同，转化方式不同：R1和R3从槲皮素出发加糖，R2从芦丁出发去掉鼠李糖，最终都指向异槲皮苷。
- 催化剂不同，所需体系不同：R1需要配套酶和供体再生，R2依靠选择性水解，R3还要考虑细胞培养及细胞内的其他反应。
- 评价制备效果要看多个方面：结合时间、投料、目标物浓度、转化效果和产物组成评价；路线整体条件不同，不能只凭一个最高数值判断哪条最好，也不能把转化率当作纯度。
