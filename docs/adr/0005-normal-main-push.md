# ADR 0005：当前main沿用公开历史，研究历史本地归档

- 状态：accepted
- 日期：2026-10-18
- 决策来源：human_direct，用户要求修复当前目录普通git push
- 负责人：项目所有者；关联TASK：TASK-009

## 背景
两条独立main导致用户原命令持续non-fast-forward；替代git publish未满足使用需求。

## 决定
当前工作区main从现有public/main创建，普通推送并设置上游；旧研究main改名为本地归档分支，原提交不改且bundle完整保存。当前tracked案例表采用远端已有脱敏表示，原表原字节保存在ignored private归档。35项本地文件恢复原路径并忽略。三篇PDF公开范围不变。

## 备选方案
继续要求用户使用独立公开检出或git publish，不能满足原命令；强推研究历史会覆盖公开父链并公开旧受限载荷，不采用；合并独立历史亦会携带旧研究父链，不采用。

## 影响与风险
当前main与远端共享历史；归档分支不得公开推送。原文件可读，历史数值原表位置已显式登记，三个状态门不变。旧公开检出无需用于日常操作。

## 复审条件
公开范围或私有资产职责改变时另定TASK；不自动重写归档或公开历史。
