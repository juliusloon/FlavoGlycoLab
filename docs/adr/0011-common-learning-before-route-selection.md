# ADR 0011：共通学习在前，规划路线在任务04选择

- 状态：accepted
- 日期：2026-10-25
- 决策来源：human_direct；任务所有者明确要求前三步未选择、任务04首选其他路线不重走流程。
- 负责人：项目所有者；工程执行：Cano
- 关联TASK：TASK-059

## 背景
原freshRun默认R1，学习记录01—04均绑定路线，selectRoute调用阶段0全量失效。由此把第一次选择R2/R3当成更换已实施的实验，迫使学生重复共通知识学习。论文阅读、路线比较、路线选择也有重复入口。

## 决定
1. 新实验run.route=null；仅阶段0且routeConfirmed=false时允许无路线。AI上下文传真实null，不用R1冒充未选择。导出/恢复保留此状态，阶段1及以后仍要求明确路线。
2. 任务01—03是共通学习，新提交的entry.route=null；旧记录中的具体route保留原字节语义，判定共通任务时不按路线失效。03的选择题针对三路线的对应关系，统一answer，不绑定当前路线。
3. 任务04及之后仍绑定具体路线；未选择路线不得靠通行词生成路线。任务04未确认前可改选，保留01—03、04文字草稿、论文笔记与首次独立判断历史；旧评价与依赖路线的后续方案/操作失效，修订号递增，陈旧AI响应不能生效。
4. run.caseFlowVersion=2只标记流程格式。旧阶段0未确认记录若缺少routeChosen=true，或旧版只有提前选择而无04已提交判断，其route恢复为空；新流程04已选未提交的草稿、旧版已明确提交04的选择及已进入后续阶段的记录保留。旧03选项可能与新题不同，保留原作答，不伪造新答案或教师通过。
5. 论文卡和笔记本对照只读取来源，不改变规划路线。任务03的解读统一放入对应论文便签；比较首页复用既有案例条件表和来源投影，不另建科学真值。
6. 参照练习是模式，配置反应体系是阶段；总结用一个主入口完成模式确认并进入阶段1。

## 备选方案
继续隐藏默认R1会让记录/评价仍带错误路线。只保留进度而改写历史route会伪造原判断。让三个路线各做一遍任务01—03与本次共通学习要求不符。

## 影响与风险
状态读取、答题门禁、恢复、AI上下文和浏览器夹具须同时接受null。04及之后的路线约束、真实观测为空、教师审定与公众发布门保持。重走共通知识不再是切换路线的副作用；修改已确认实验仍失效依赖它的后续数据。

## 复审条件
未来课程明确要求逐路线独立的前置学习时，由具名教师审定并另立TASK/ADR；不得隐式恢复默认路线或改写旧独立判断。
