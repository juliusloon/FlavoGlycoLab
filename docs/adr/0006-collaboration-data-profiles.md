# ADR 0006：默认公开开发配置与可选离线研究包

- 状态：accepted
- 日期：2026-10-20
- 决策来源：human_direct（所有者要求解决团队克隆/运行/数据协作）；技术方案由agent选择。
- 负责人：龙锦轩；执行者：Cano
- 关联TASK：TASK-013

## 背景
GitHub停留在TASK-009；本机已完成的实验台未提交。旧默认manifest与测试同时要求私有研究池，导致成员误以为项目必须访问所有者服务器。实际学生过程演练不消费3059记录、旧模型或受限原件。

## 决定
1. 默认public配置：代码、原创路线摘要、22条待审登记、来源元数据与已明确授权公开的三个PDF随Git交付。无需包下载、服务器账户、Conda、GPU、npm或模型凭据即可启动；public的研究record_count=null，不能假装全量数据已加载。
2. research配置显式选择，保留原始记录SHA。缺失报操作指引，损坏报错，无隐式回退；全量研究测试显式开启。
3. 团队研究交接使用本地tar.gz包及另行给出的SHA，导入前核验整包/文件清单/固定SHA。只取登记的117项现存证据与4项v3派生文件，五项external_model不构成依赖。禁止把包、private、模型凭据、旧研究历史公开。
4. 全部运行/数据落点在本项目内。离线包来源文件可以是接收方下载/拷贝得到的任意路径，不需要登录服务器；字节不匹配不覆盖。完整预检后才写入，同字节重复导入无副作用。
5. 数据准入、许可与三个科学/教学/发布门继续独立；内部交接工具不声明第三方持权方批准，不公开受限记录，不代签教师审核。
6. 三个公开PDF的精确路径/SHA从导出脚本常量迁至metadata/public_sources.json唯一维护；PUBLIC_PDFS继续加载该登记，兼容历史测试/工具。v3四项指纹唯一维护于metadata/research_bundle.json，原件仍只登记于source_registry.csv。

## 备选方案
- 把全部私有数据直接提交公共Git：扩大第三方材料分发，混入模型且体积大，运行仍不需要这些数据。
- 要求每位成员登录所有者服务器：无法独立开发，凭据和机器配置难复现。
- 伪造一套科学演示数据或静默返回空列表：掩盖缺失与真实数据边界。

## 影响与风险
旧调用若依赖默认records()必须改为EvidenceCatalog(workspace, "research")；日常索引读取改用cases()。研究包仍包含权利未核实的第三方材料，只能按团队实际具备的使用权限交接；不上传公共Git/Release/网页。不自动发送给任何成员。离线SHA确保与提供方文件一致，不替代身份或版权核验。Windows/macOS运行可由CI检查Python/JS；浏览器外观与另三位成员的实际设备须分别实测。

## 复审条件
引入经教师审定的观测、明确可再分发的大规模数据集、账户/跨设备记录或正式发布时，新TASK重新登记manifest/权限/版本，不能静默改变public默认语义。
