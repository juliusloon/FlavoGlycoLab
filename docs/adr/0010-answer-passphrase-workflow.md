# ADR0010：本地答题通行词的流程语义

- 状态：accepted
- 日期：2026-10-25
- 决策来源：human_direct，所有者明确要求所有回答框输入admin7直接放行、不走AI导师评价。
- 负责人：项目所有者；工程实施Cano。
- 关联TASK：TASK-052。

## 背景
原流程分原生输入约束、主线确定性核对、AI评价及存档推导门禁。只在点击事件跳过AI仍会被字数、必选项或刷新后的进度判断阻断。

## 决定
统一使用learning-state.js的isAdminPass，对trim后严格等于admin7的完整回答放行；不接受大小写变体、包含子串或近似词。只针对当前回答，逐题保留前序及实际操作依赖；方案数值、许可、真实观测与教师审核边界不变。

主线记录仍以既有entry的recorded、route、note为唯一真值，不增加全局解锁标记。该词优先于字数、选项匹配和AI判定；eval.mode=admin_override并单独显示“通行词已放行”，不称为导师评价，也不生成首次独立判断。修改回答立即撤销放行，换路线沿用原失效规则。导入文字入口与导师输入也可作用于当前问题；方案假设、参照理由、分析边界和最终反思分别豁免自身文本长度。

## 备选方案
- 仅在AI请求前截断：无法穿过原生约束或存档后的确定性核对。
- 一个全局完成/管理员布尔值：复制进度真值，容易将所有未来问题及跨路线结果误解锁。
- 把通行词替换成标准答案：伪造学生判断，掩盖人工指定的流程放行。

## 影响与风险
这是所有者授权的LAN原型答题捷径，不提供身份鉴权、教师权限或访问安全。代码和前端资产可读，该词不能作为秘密凭据。记录/导出保留admin_override语义，不推进research_evaluation、teaching_case_review或public_teaching_release。真实教学评分/对外发布前应独立复审该行为。

## 复审条件
开始实现正式成绩、教师身份/权限、服务器存档或公众教学发布时，重新审定通行词的可用范围、审计与关闭方式，以新ADR显式替代。
