# ADR 0003：FlavoGlycoLab 项目名称与命名身份

- 状态：accepted
- 日期：2026-10-15
- 来源：human_direct（所有者要求按核心目标重命名；具体名称由执行者据此选择）
- 关联TASK：TASK-002

## 背景
FutureHealth过于宽泛，易被误读为通用医疗健康产品；实际主题是健康相关黄酮糖苷的AI辅助酶法合成、生物制造与虚拟仿真实验。新项目须完全独立，不依赖旧研究Git。

## 决定
英文/代码/仓库目录统一使用FlavoGlycoLab（Python package为flavoglycolab），中文为“黄酮糖苷智能生物制造虚拟实验室”。原临时名字只留在不可变的迁移溯源和历史Git/ADR中。课程主题保留正式全称“AI赋能健康相关黄酮糖苷的酶法合成与生物制造虚拟仿真实验”。

## 备选方案
FutureHealth：范围不准确；GlycoHealthLab：难以体现黄酮类专门领域；FlavoGlycoLab：能指向黄酮糖苷与实验教学，同时不过早承诺已经具备酶法产率AI预测。

## 影响与风险
仓库目录和Python包更名可能使外部挂载地址/本地脚本失效；必须更新挂载或项目指向。历史迁移审计不应被错误重写；更名不改变任何源文件许可和教师审定状态。不在当前任务中制作品牌商标/验证独占使用权。

## 复审条件
正式课程命名由学校/专家变更，或品牌/权利核查出现冲突。
