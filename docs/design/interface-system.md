# 页面与界面组件规范

TASK-037建立，TASK-039—046更新，2026-10-25。适用于当前学生端，保留原生 HTML/CSS/ES 模块；无需前端构建器或新增运行依赖。页面只投影已有学习状态，不建立另一套科学、教学或学习完成真值。

## 导航与恢复

- 所有页面取消顶部站点栏，固定左下“标题｜更多”。标题链接至实验总览，继续练习使用总览与资料页现有入口。更多是向上展开的原生popover，恰有“开启新实验 / 实验记录 / 设置”三项；保存状态在菜单内显示，保存异常也在更多按钮上保留提示标记。支持外部点击、Esc关闭及方向键/Home/End导航；关闭设置、逆合成或取消新实验后回到可见的更多按钮。
- 新实验保留原确认与历史记录逻辑；独立案例/数据/组件页经`index.html#new`请求同一确认，不能直接清空草稿。操作条与菜单分别固定在底部及其上方，页面为操作条预留底部滚动空间。导航收起时左下仅保留总览图标，隐藏更多；展开任一组后恢复标题/更多，与右下AI图标分开。
- “设置→开发者模式”是原生dialog内的二级details入口，包含论文对照、案例页、数据查询和界面规范。工作台另有逆合成导入；它只是入口归组，不是访问鉴权。各页面仍保留原有URL和任务内论文/数据入口。
- “设置→资料与审定状态”集中说明案例和教学内容待教师审定，提供参考文献/许可及数据来源登记入口；开发者模式与审定资料各用一个独立原生details。
- 学习页仅使用左侧主线任务与实验历程定位；移除顶部共享返回条、局部任务导航、重复任务编号和开发矩阵，不增加面包屑栏。保留叙事分页、提交、下一项及完成探究等真实流程操作。
- 左栏主线任务、实验历程各为一层卡片，标题右侧按钮可分别收起内容；默认展开。本阶段全部四任务有可换行的行动介绍；进度/高亮、勾选、disabled及aria-current表达状态。两组都收起时，桌面变为56px窄栏，主线/历程恢复入口及左下总览入口均为56×56px方形；不显示更多。单组展开即恢复宽度及更多。手机两组恢复图标并排置于正文前，底部总览同为方形。折叠不会重绘正文、销毁分子或修改练习。六阶段与总览仍共享路线/烧瓶/条件调节/取样/分析/报告图标。
- 论文、记录、锁定/未知页及独立资料页保留“返回上一页”和“继续当前练习”。有站内历史时使用浏览器历史；直接进入且无站内历史时返回实验总览。浏览器自身前进/后退同样有效。
- 任务和阶段地址随真实进入操作更新，通过原生 history/hash 导航。输入仍由既有草稿逻辑保存，切页不提交答案、不重置实验。
- `flavoglycolab.last-page.v1` 只保存学习页面路径，是界面偏好。恢复前重新按当前答案和操作条件检查权限，不能凭旧路径恢复已失效的完成状态。
- `flavoglycolab.sidebar.v1` 仅保存`quests`/`workflow`两个折叠布尔值，跨刷新恢复；不写入学习记录、导出、答案或解锁状态。存储不可用时仍可在当前页面收起/展开。
- 原学习记录仍唯一保存在 `flavoglycolab.workbench.v1`，保留旧存档迁移、损坏不覆盖、跨标签页冲突保护。续接仅限当前浏览器和站点源。
- 进入新页面将主内容滚至顶部并聚焦主区域；叙事分页继续使用现有 sessionStorage 偏好。没有账号、跨设备恢复或网络同步。

## 组件调用

普通页面在 HTML 内加载 `components.css`，提供 `<footer data-site-controls></footer>`，再由模块挂载。学习页继续使用原 app 编排；`mountSiteHeader`/`siteHeader`保留兼容函数名，实际产出左下控件，不产出顶部站点栏。

```js
import {
  mountSiteHeader, bindReturnNavigation, returnControl,
  pageHeader, panel, button, field, statusBadge, emptyState,
} from './components.js';

mountSiteHeader('data'); // home / bench / papers / case / data / records / components
bindReturnNavigation(); // 每个文档只绑定一次
main.innerHTML = returnControl()
  + pageHeader({title:'页面标题', description:'说明用途'})
  + panel({title:'内容', body:button({label:'继续练习', href:'./index.html#/resume'})});
```

| 函数/类 | 参数与规则 |
| --- | --- |
| `button` | `{label, href?, action?, variant?, disabled?, type?, iconName?}`；primary/secondary/quiet；链接导航、按钮动作；一组通常一个主动作 |
| `field` | `{label,name,value?,unit?,type?,attributes?}`；默认text；数字输入保留step="any"；attributes仅用于开发者固定的min/max/required等属性 |
| `pageHeader` | `{title,description?,actions?}`；actions只接收可信组件HTML |
| `mountSiteHeader` / `settingsDialog` | `(active,{workbench?})` / `({workbench?})`；同步挂载左下控件、向上菜单及唯一共享设置；工作台新实验/导入事件由app编排 |
| `sidebarToggle` / `syncSidebarPanels` | 导航组按钮与独立折叠偏好；刷新导航投影后恢复DOM状态，不改学习真值 |
| `panel` | `{title?,body?,id?}`；body只接收可信组件HTML |
| `statusBadge` | `(label,tone?)`；neutral/success/warning/danger |
| `emptyState` | `{title,description?,actions?,tone?}`；解释原因并提供恢复入口 |
| `.fg-container` / `.fg-split` | 页面容器/两区布局，不在每个页面重写尺寸 |
| `.field` / `.actions` | 对于select/textarea等复合表单，沿用同一标签和操作区样式 |
| `.fg-table-wrap` / `.fg-table` | 响应式表格容器/表格；列标题、行标题用scope |

普通文本参数由组件转义。`body`、`actions`、`attributes` 仅限源码构建的可信HTML/属性，不放入学生、模型、来源或URL原始输入。按钮事件由页面编排处理；组件库不持有实验状态、不调用AI、不自行保存答案。

## 状态与无障碍

- 加载、空、失败、未解锁分别解释；失败提供重试或返回入口。缺失值、原文报告、学生草稿和本次观测不混用。
- 有明确表单标签、键盘焦点、禁用态与 `role="status"`；紧急错误沿用 `role="alert"`。原生dialog支持Esc、焦点约束和关闭后回焦。
- 不仅以绿色文字表示可操作；按钮有边框/背景，普通链接保留下划线或明确导航形态。
- 页面主体使用main、单一内容标题；跳转入口保留skip-link。组件展示页的空状态是独立示例区域。
- 动效尊重 `prefers-reduced-motion` 及现有减少动态偏好。
- 不通过CSS隐藏科学/教师审定边界；机器检查永不自动晋级三个状态门。

## TASK-047：实验速览与论文笔记本

第三幕保留三张研究卡，以右侧六阶段速览和“开始主线探究”说明完整流程；取消论文点击计数、阅读提示及路线0/4门槛文案。前两幕顺序判断和24任务顺序保持不变。任务01“论文与解读”的三张简要卡与阶段对照按钮进入同一个笔记本；导入研究卡直接打开对应论文。

笔记本图标在学习应用body级右下常驻，与导师入口同宽48px并共用右边缘。原生dialog居中占屏幕大部分，白色阅读页与左侧四图标短便签，便签下方透明无底板；对比便签复用现有阶段矩阵和结论反思，另三便签各含对应PDF/阅读指引/学生笔记。桌面原文与笔记并排，手机上下排列，左便签始终可见。TASK-050删除header标题/副句，便签只显示对照/双酶/去糖/全细胞四种SVG图标，完整论文名保留在aria-label/title。关闭按钮独立浮在内容右上。方向键/Home/End切换，Esc或关闭按钮退出并回焦。TASK-062移除笔记本“问导师解读此篇”入口；导师面板及同一个右下启动按钮均跟随论文modal的焦点范围显示在上层；在笔记本内可直接点击图标启动/关闭后再次启动导师，导师内Esc只关闭导师并回焦图标。

每篇笔记最多8000字符，输入即保存，来源限三个既有source_id，旧记录缺字段补空，异常类型/长度拒绝读取。笔记不与任务01的答题笔记混合，不触发通过/AI请求/观测；随当前实验导出和快照，换路线保留、新实验清空。PDF只读取既有同源受控端点；TASK-050改为本地固定PDF.js逐页内容显示，白底、无工具栏/目录，桌面24px内边距/32px底边，手机14px横向/24px底边；canvas保留原页比例，文本层可选择，页外背景白色。加载/较慢/失败状态按需出现，失败可重试/原文新标签页。删除指定常驻保存/权利说明；成功保存不显示文字，失败仍提示。模块与记录边界见ADR0009。

TASK-051：四个便签均使用轨道全宽（桌面/平板52px、手机42px），选中和未选中共用width:100%，右沿直接衔接正文左沿；原48/44px高度、图标、颜色和透明轨道保持。

### TASK-052：分子辨析合页与通行词

任务02只有一个内容页，同屏包含探究文字、五个仅显示名称的小按钮（36px高、按内容宽度、窄屏换行）、所选分子的本地3Dmol、可聚焦糖基/复位与讲解；EMIQ标明Q3M代表组分，来源及二维降级随选择变化。切换只更新模型及说明，保留右侧答题草稿；不显示“计算构象 · 可拖动旋转、滚轮缩放 · 待教师审定”常驻句，来源与审核元数据仍在原资产中。

所有答题文本完整输入admin7（忽略两端空白、严格区分大小写），提交后当前回答直接放行，不要求选择题作答或8/15字，也不请求AI评价。TASK-062删除导入两题的快捷通行输入；历史通行记录仍兼容，导师输入同样可放行当前问题。主线、假设搭建器、方案假设、参照理由、分析边界及反思采用统一匹配；数值输入、阅读笔记及实际操作不属于答题放行。主线单独显示“通行词已放行”，不显示为导师评价/首次独立判断。编辑后撤销，存档仍按原路线/顺序推导进度。长期语义见ADR0010。


### TASK-053：提交、草稿与分析反馈

主线提交进入评价中时显示loading并禁用重复提交，完成评价后从同一回答记录推导进度和“下一项任务”；选择题仍须通过确定性核对。编辑立即撤销旧反馈与推进、取消请求并恢复提交；刷新中断显示可重试的降级状态。服务不可用时明确按既有自查记录，不伪装AI已通过。切题显示任务编号及“新任务，输入框已清空”或“已载入草稿/已提交回答”。任务04在回答框旁选路线，再填写依据；其他路线标明可选。

分析台以四个可用左右/Home/End键操作的页签显示，每次仅一回合；取样记录默认折叠并保留展开偏好。参照理由、边界说明的未提交输入在当前页面会话内切页/局部操作后保留，刷新只恢复已经提交的分析记录。方法卡从原value/conditions共同读取，未知显示“本条记录未登记”，不把终止/供体条件充作反应条件。

方案按R1分别记录UGT/GmSUS、R2记录鼠李糖苷酶活性浓度（mU/mL，可留空），即时换算每管mU，明确为学生设计值；R3不强加游离酶单位。装配选择后在邻近按钮提示加入，成功卡片显示勾选。关键只读状态14px高对比；糖基在3D/2D中以橙红色突出并提供文字状态，复位清除。导入选择题按正常选项作答，不再展示快捷通行入口。
