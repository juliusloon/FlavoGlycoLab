## 使用流程
1. 旋转、缩放异槲皮苷结构，突出糖基，展开三种思路。
2. 查看Pei2019、Zhang2015、Niu2024的方案与证据；比较只改变浏览对象，明确点选才改变规划路线。
3. 完成左上01—04主线：明确任务、辨识身份、比较路线、留下独立选择理由。错误留关，短答保存为待复核自述；不计正式成绩。
4. 用第04题的选择理由确认路线，依次配置体系、设计条件、操作取样、审查分析与反思。各阶段主线和必要操作共同控制推进，左下历程可回访。
5. 每一阶段都能并排查看三篇论文的研究做法、条件语义、假说、证据与局限。
6. 保存练习，比较历史快照或导出JSON/Markdown。

右下48px纯图标AI导师随时可唤出，默认不占主空间。Enter发送，Shift+Enter换行，中文输入法确认不误发；真实模型答复、证据拒绝、失败分别显示。AI只帮助核对，不替学生操作。设置支持减少动态效果、记录入口和重看分子开场。配置Qwen时状态显示“Qwen · 实时辅导”，当前阶段/主线以按钮显示，点击返回对应任务；未配置或连接失败时如实降级，实验台可继续。

“设置→开发者模式→数据查询”进入独立只读页：检索21条已登记文献报告值（R1 9、R2 5、R3 7），可按路线/来源/类别/关键词筛选并支持`?route=`深链；每条显示原指标、条件、原文定位、使用边界与“原文报告 · 非本次观测 · 待教师审定”。无匹配时显示“没有对应实验数据”，不生成0、预测或路线排名；页面不调用AI、不读写学习记录、不请求第三方资源。案例页与“查看分析结果”均有入口。

24项主线答案与理由自动保存草稿，提交后形成自查记录。任务按LYW v5实际矩阵六界面各4步排列（01—04、05—08、09—12、13—16、17—20、21—24），每项显示任务标题；底层审核状态保持待教师审定，数据依赖与实际矩阵字段保留。04、09、13—22共12项登记为数据依赖（沿用TASK-019代理设计，LYW实际稿未给该角标）。实际稿未给分钟、分值或成绩类型，网页不展示未提交量规，也不计成绩。三篇论文对照新增“结论与反思”页签，展示14字段×3路线、21条历史命中边界与4条明确标注“原文报告、非本次观测”的文献值，不改变已选路线。04/09的首次AI前判断单独保留，换路线不追认新的“未经AI”判断。09假设搭建、17证据分类、20证据链是临时探究工具；09四字段须点击带入，成为可编辑/保存的假设草稿。上游变更清除对应下游当前答案，已保存快照保留。

## 运行
从根目录运行`python scripts/dev.py`，浏览器打开[本机实验台](http://127.0.0.1:8767/)。Python3.10+标准库，无需npm、GPU、私有数据或模型凭据；无AI配置仍可完成练习。Windows可用py，macOS/Linux可用python3。不要双击index.html。

获取/更新、默认检查、可选研究包及AI配置见[协作说明](../../docs/operations/collaboration.md)。原生HTML/CSS/ES模块，无构建器/CDN；3Dmol2.5.5及结构均随项目离线加载。分子来源、计算方法和许可证见[结构资产说明](assets/molecules/README.md)。WebGL不可用时自动显示同源二维结构与SMILES。

## 文件职责
- app.js：事件编排、持久化、分子生命周期、浮窗、同源AI及陈旧回复保护。
- data.html、data-page.js、data-query.js、data-page.css：独立只读数据查询页、筛选逻辑与样式；`content/demo-content.json.data_query`为唯一内容源。
- lab-state.js：六阶段约束、校验、上游失效、记录及导出。
- learning-state.js：学习草稿、自查、独立判断及失效。
- quest-state.js：基于已存回答计算顺序解锁/进度，无另一份完成状态。
- views/inquiry.js：分子/路线场景、精简任务导航、任务视图、三论文对照及结论/反思视图。
- paper-notebook.js / paper-notebook.css：四便签阅读浮窗、同源PDF加载/重试与笔记交互；笔记唯一保存于lab-state.js的run.paperNotes。
- paper-pdf-reader.js：同源三PDF逐页渲染、可选择文本层与资源生命周期；vendor/pdfjs/provenance.json唯一登记所用第三方库/许可/指纹。
- views/inquiry-tools.js、inquiry-tools.css：证据分类、假设搭建、证据链操作。
- molecule-viewer.js、assets/molecules/、vendor/3dmol/：本地可视化、计算结构、许可与降级。
- views/workbench.js：阶段2—6操作与实验记录；views/learning.js：学习记录投影。
- ui.js：转义与图标；styles.css：空间布局、响应式与动态偏好。
- content/demo-content.json：路线/来源、24项练习及三案例六阶段原创非数值投影。

原sidebar-resize.js是TASK-017历史辅助模块，新界面不再加载或依赖；旧宽度偏好不影响新浮窗。原资产lab-bench.png为原创生成装置示意，不是实拍数据。

仅保存于当前浏览器和站点源，两个LAN地址不共享存储。最多12快照；新实验须确认，损坏存储不静默覆盖，可导出原始备份。其他标签页修改时暂停本页写入并提示，避免覆盖。

## 科学边界
结构是计算可视化；条件是学生方案，论文对照未提供准入的推荐数值。没有本次样品真实色谱、标曲、产率或动力学模型，quantitative_result保持null。主线自查不代替科学校验、正式课程成绩、教师审核或公众教学发布验收。

TASK-052：任务02将探究与五类分子比较合为一页，点击按钮切换对应3Dmol和讲解；EMIQ显示明确标记的Q3M代表组分。结构来源/许可及计算方法见assets/molecules/README.md。

答题框输入`admin7`后提交可直接放行当前问题，不调用AI导师评价，记录标识为`admin_override`。导入有快捷通行输入，导师输入框也支持；普通回答规则保持。该功能是本地原型流程捷径，不是教师身份、科学结论或正式成绩；不跳过实际操作及数值格式校验。


TASK-053：提交时显示评价进度，编辑取消旧请求，刷新后保留回答并可重试；切题明确提示载入/新建草稿。分析台四回合用页签切换，取样记录可折叠；未提交分析文字仅在本页面会话内保留，正式保存仍以“选为参照/记录边界说明”等动作为准。方案增加可选、分酶的mU/mL字段和每管mU换算，仅记录学生设计；旧记录可继续打开。快捷通行默认折叠，导入跳题需确认；普通答题与admin7语义不变。
